# Launchpad Basics

The Novation Launchpad is a grid controller used for music production and performance. It consists of an 8x8 grid of RGB pads that can trigger clips, play notes, and control your DAW.

## How it Works

At its core, the Launchpad sends MIDI data to your computer. When you press a pad, it sends a "Note On" message. Your software (like Ableton Live) receives this message and produces sound.

Conversely, the software can send MIDI data *back* to the Launchpad to light up the LEDs. This is how "Light Shows" are created.

## Grid Layout

The standard Launchpad grid is 8x8 (64 pads).
-   **Rows** often correspond to different sounds in a Drum Rack (e.g., Kick, Snare, Hi-Hat).
-   **Columns** can represent time or different variations.

In this simulator, each row in the sequencer maps to a row on the Launchpad. The column that lights up moves with the beat, creating a scanning effect.
