Lights in a launchpad performance represent the second half of the magic you see on the screen, and is also probably why you clicked on a launchpad video in the first place. 
Unless you clicked on one for the song that is.

There are a multitude of ways lights can be made; chain lights, MidiExt, and Apollo Studio. Each has their own strengths and weaknesses, and each can be used to create stunning visual performances.

## Software Options
- Ableton with MidiExt
- Ableton with Chain Lights
- Apollo Studio
- Unitor / Unipad (mobile apps)
